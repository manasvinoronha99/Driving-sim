🎭 Shadow Memory Game

Simon-says style game with your body!

1. Watch the colored shadow pattern displayed on screen

2. Memorize which body parts light up in which colors

3. Recreate the pattern with your body within the time limit

Color coding:

  • 🔴 Red: Left arm raised
  • 🔵 Blue: Right arm raised
  • 💚 Green: Arms spread (T-pose)
  • 🟡 Yellow: Crouch down

Patterns get progressively more complex!
